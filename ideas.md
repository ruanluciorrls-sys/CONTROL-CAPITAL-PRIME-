# Brainstorm de Design - Relatório CPA 2026

## Análise dos Dados

O arquivo RELATÓRIOCPA2026.xlsx contém múltiplas abas com dados de relatórios de CPA (Custo Por Aquisição), organizados por:
- **Grupos**: GRUPO 888, GRUPO MANGA, GRUPO A8, GRUPO ANJO, GRUPO VOY
- **Métricas principais**: Depósito, Meta, Média, Prazo, Link das Filhas, Responsável
- **Estrutura**: Tabelas com # (número), Depósito (valores), e outras colunas de dados
- **Período**: Principalmente Outubro e Novembro de 2025

### Design 1: Minimalismo Corporativo Moderno

**Design Movement**: Minimalismo corporativo com influências de design de dados modernos

**Core Principles**:
- Clareza absoluta com hierarquia visual forte
- Espaço em branco generoso para respiração visual
- Tipografia sans-serif limpa e precisa
- Foco em dados, não em decoração

**Color Philosophy**:
- Paleta neutra: Cinzento profundo (#1F2937) como base
- Azul corporativo (#2563EB) para destaques e CTAs
- Verde (#10B981) para métricas positivas
- Vermelho (#EF4444) para alertas
- Fundo branco puro com sutis separadores cinzentos

**Layout Paradigm**:
- Grid de 12 colunas com alinhamento rigoroso
- Sidebar esquerdo para navegação de grupos
- Painel principal para tabelas e gráficos
- Cards informativos com sombras minimalistas

**Signature Elements**:
- Tabelas com linhas alternadas sutis
- Badges para status (Ativo, Inativo, Pendente)
- Ícones Lucide React em tons cinzentos
- Separadores horizontais delgados

**Interaction Philosophy**:
- Hover states com mudança de cor sutil
- Transições suaves de 200ms
- Tooltips informativos ao passar o mouse
- Cliques imediatos sem animações excessivas

**Animation**:
- Fade-in ao carregar dados
- Slide suave de painéis
- Pulse suave em números importantes
- Transições de cor em 300ms

**Typography System**:
- Títulos: Poppins Bold (24px, 28px)
- Subtítulos: Poppins SemiBold (16px, 18px)
- Corpo: Inter Regular (14px, 16px)
- Números: Mono (12px, 14px) para dados

## Design Escolhido

**Minimalismo Corporativo Moderno** foi selecionado como abordagem principal.

Este design oferece:
- Clareza máxima para leitura de dados
- Profissionalismo apropriado para relatórios CPA
- Fácil manutenção e escalabilidade
- Foco absoluto nos dados, não em decoração
- Compatibilidade com tabelas e gráficos
